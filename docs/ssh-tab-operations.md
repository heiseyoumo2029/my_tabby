# SSH 标签操作

- SSH 工具栏中，连接信息旁的三个按钮分别一键复制主机地址、端口和地址加端口。地址来自配置，不会将域名解析为 IP。
- SFTP 工具栏的“排序”菜单支持文件名 A→Z、Z→A，以及修改时间从旧到新或从新到旧；目录始终排在文件之前。排序设置在当前 SSH 标签存活期间保留，筛选和切换目录后仍然生效。
- “重连所有 SSH 标签”包含分屏中的 SSH 标签。弹窗可选择仅重连已断开的会话，或重连全部（会中断已连接的 shell）；正在连接的会话会跳过。不重连本地终端、Telnet 和 Serial。
- SFTP 的“终端目录”使用 shell 上报的工作目录。tmux 中可在 SFTP 工具栏打开 `tmux` 菜单，选择具体 pane；路径通过单独的 SSH 通道查询，不依赖 shell 上报。默认查询当前 SSH 登录用户的默认 tmux 服务端。若交互 shell 中使用的 tmux 不在非交互 SSH 的 PATH 中，或版本与默认客户端不同，可将 `command -v tmux` 的绝对路径填入可执行文件路径；若使用自定义 socket，可将 `tmux display-message -p '#{socket_path}'` 的结果填入 socket 路径并刷新。这两个设置在当前标签存活期间保留。不同用户或嵌套 SSH 中的 tmux 不属于当前 SFTP 连接，不能直接查询。
- SFTP 文件右键选择“发送到 SSH 标签”，选择目标标签后，在弹窗中输入目标主机上的绝对目录路径。弹窗默认填入目标标签当前的 SFTP 目录，也可以先在目标标签的 SFTP 面板中打开需要的目录。确认时会检查目录是否存在；目标文件已存在时不会覆盖。文件以分块方式经本机内存中转，传输面板可以显示进度和取消。取消或失败时会尝试清理未完成的目标文件；若目标连接已断开，可能需要手动删除残留文件。
- SFTP 中右键目录选择“下载目录”，桌面版可选择本地保存位置，递归下载并显示进度；Web 版暂不支持目录下载。
- 文件或目录右键“发送到 SSH 标签”可复制到另一个 SSH 标签；发送弹窗默认采用目标标签终端上报路径，若在目标 SFTP 的 tmux 菜单中选择过窗格则优先使用该窗格路径，也可在弹窗选择窗格、SFTP 目录或手动输入。目标已存在时不会覆盖；符号链接暂不支持，目录内存在符号链接时整次传输会失败并尝试清理。
- SSH 工具栏可切换“自动目录 / 手动目录”，控制复制路径、打开 SFTP 和跨标签传输时的默认目录。自动模式优先通过独立 SSH 通道只读查询远端 Linux `/proc`，关联当前 SSH 连接的唯一终端及前台 shell，或按客户端终端查询 tmux 活动窗格；无需修改远端配置。不可用时可使用 shell 的 OSC 目录上报。手动模式可填写绝对路径，或清空输入并在 SFTP 的 tmux 菜单选择窗格；手动路径优先于手动窗格。模式和配置仅在当前标签存活期间保留。
- 自动模式依赖远端 Linux、Python 3、可读 `/proc`、同一个 SSH 连接中唯一可识别的伪终端；多 shell 共享连接、权限限制、嵌套 SSH、前台非 shell 进程、非 Linux 服务器及不同账号的 tmux 可能无法识别，此时选择手动模式。自动探测不向交互终端发送输入，也不会修改远端 shell 配置。
- SSH 交互 shell 需上报 OSC 7 或 OSC 1337 目录。未配置上报时客户端无法从独立 SSH 命令安全推断交互 shell 的当前目录；例如 Bash 可在远端 `~/.bashrc` 中追加 `PROMPT_COMMAND='printf "\\033]1337;CurrentDir=%s\\007" "$PWD"'`（已有 `PROMPT_COMMAND` 时应合并而非覆盖），重新登录后生效。tmux 中可通过 SFTP 的 tmux 菜单明确选择窗格，无需依赖 shell 上报；嵌套 SSH 和不同账号的 tmux 不属于当前连接。
- 双击 File transfers 中的本地下载项：文件会在文件管理器中定位，目录会直接打开；上传及远端中转任务没有本地路径，不执行打开操作。
