# SSH 标签操作

- SSH 工具栏中，连接信息旁的三个按钮分别一键复制主机地址、端口和地址加端口。地址来自配置，不会将域名解析为 IP。
- “重连所有 SSH 标签”包含分屏中的 SSH 标签。弹窗可选择仅重连已断开的会话，或重连全部（会中断已连接的 shell）；正在连接的会话会跳过。不重连本地终端、Telnet 和 Serial。
- SFTP 的“终端目录”使用 shell 上报的工作目录。tmux 中可在 SFTP 工具栏打开 `tmux` 菜单，选择具体 pane；路径通过单独的 SSH 通道查询，不依赖 shell 上报。默认查询当前 SSH 登录用户的默认 tmux 服务端；使用自定义 socket 时，在该标签的 tmux 菜单输入 socket 绝对路径并刷新。不同用户或嵌套 SSH 中的 tmux 不属于当前 SFTP 连接，不能直接查询。
- SFTP 文件右键选择“发送到 SSH 标签”，选择目标标签后，在弹窗中输入目标主机上的绝对目录路径。弹窗默认填入目标标签当前的 SFTP 目录，也可以先在目标标签的 SFTP 面板中打开需要的目录。确认时会检查目录是否存在；目标文件已存在时不会覆盖。文件以分块方式经本机内存中转，传输面板可以显示进度和取消。取消或失败时会尝试清理未完成的目标文件；若目标连接已断开，可能需要手动删除残留文件。
- 当前跨标签传输只支持普通文件；目录和符号链接不支持。两端均须保持 SSH 连接，尚不支持断点续传。
