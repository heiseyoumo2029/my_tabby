# SSH 标签操作

- SSH 工具栏中，连接信息旁的复制菜单提供主机地址、端口和地址加端口。地址来自配置，不会将域名解析为 IP。
- “重连所有 SSH 标签”包含分屏中的 SSH 标签，会中断当前会话；不重连本地终端、Telnet 和 Serial。
- SFTP 的“终端目录”使用 shell 上报的工作目录。tmux 中可在 SFTP 工具栏打开 `tmux` 菜单，选择具体 pane；路径直接查询 SSH 主机上默认 tmux 服务端，不依赖 shell 上报。使用自定义 tmux socket 时此菜单无法自动发现该服务端。
- SFTP 文件右键选择“发送到 SSH 标签”，选择目标标签。目标位置为该标签当前 SFTP 目录，菜单中显示路径；目标文件已存在时不会覆盖。文件以分块方式经本机内存中转，传输面板可以显示进度和取消。取消或失败时会尝试清理未完成的目标文件；若目标连接已断开，可能需要手动删除残留文件。
- 当前跨标签传输只支持普通文件；目录和符号链接不支持。两端均须保持 SSH 连接，尚不支持断点续传。
